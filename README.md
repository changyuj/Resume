# Yu Ju Chang - Professional Resume Website

A professional, responsive resume website built to showcase the technical expertise and career trajectory of Yu Ju Chang, a Senior Cytogeneticist and aspiring Full-Stack Developer.

## 🚀 About the Developer

**Yu Ju Chang** is a highly analytical professional with over 16 years of experience in cytogenetics at MD Anderson Cancer Center. Combining a background in Biology with degrees in Computer Science and Cybersecurity, Yu Ju is dedicated to bridging the gap between scientific rigor and innovative technology solutions.

- **Current Role**: Senior Cytogeneticist
- **Education**:
  - M.S. in Cybersecurity and Information Assurance (WGU)
  - B.S. in Computer Science (Oregon State University)
  - B.S. in Biology (UT Austin)
- **Interests**: Full-Stack Development, Cybersecurity, AI Agents, and innovative problem-solving.

## 🛠️ Tech Stack

- **Structure**: Semantic HTML5
- **Styling**: Custom CSS3 (Vanilla)
- **Logic**: Vanilla JavaScript
- **Data**: JSON-based dynamic content loading

## 📁 Project Structure

```text
Resume/
├── css/            # Stylesheets for design and layout
├── assets/         # Images and static resources
├── public/
│   ├── data.js     # Centralized resume data (education, work, skills)
│   └── app.js      # Main logic for dynamic content injection
├── index.html      # Main entry point for the resume website
└── README.md       # Project documentation
```

## 💻 How to Use

1. **Viewing**: Open `index.html` in any modern web browser to view the resume.
2. **Customizing**: Edit `public/data.js` to update personal information, work history, or project details. The website will automatically reflect these changes.
3. **Styling**: Modify `css/style.css` to adjust the visual design and layout.
